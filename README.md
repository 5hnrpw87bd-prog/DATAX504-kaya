# DATAX504 — Kaya

Course assignments for DATAX504.

## Final project

[Corporate Bankruptcy Risk Prediction](final_project/README.md)

A cost-sensitive comparison of logistic regression and a compact Keras MLP on
the UCI Taiwanese Bankruptcy Prediction dataset. The selected model reaches test
AP 0.3145 versus a no-skill 0.0323; the report examines class weighting and
decision thresholds under hypothetical error costs.

- Notebook: `final_project/bankruptcy_prediction.ipynb`
- Setup and reproduction: `final_project/README.md`
